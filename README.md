# RuangBicara — Web Edukasi & Simulasi Belajar Berkomunikasi

**RuangBicara** adalah aplikasi web interaktif berbasis HTML, CSS, dan JavaScript murni (*Vanilla JS*) yang dirancang untuk membantu pengguna memahami dasar-dasar komunikasi efektif serta melatih kemampuan merespons situasi sosial secara asertif dan empatik.

## Fitur Utama

- **4 Pilar Komunikasi Efektif**: Ringkasan konsep *Active Listening*, Komunikasi Asertif, Empati & Validasi, serta Bahasa Non-Verbal.
- **Simulasi Dialog Interaktif**: Latihan studi kasus percakapan sehari-hari lengkap dengan sistem skor dan umpan balik langsung (*instant feedback*).
- **Checklist Praktis**: Panduan interaktif sebelum memulai percakapan penting (seperti teknik *I-Statement* dan parafrase).
- **Desain Responsif**: Nyaman diakses melalui perangkat desktop maupun ponsel.
